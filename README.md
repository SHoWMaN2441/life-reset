## 🎯 Loyiha haqida

**Life Reset 66** — foydalanuvchiga 66 kun davomida o'z hayotini qayta qurish imkonini beruvchi to'liq stack veb-ilova. Ilmiy tadqiqotlarga asoslangan metodlar: Sirkadian ritm, Dopamin detoks, Box Breathing, Pomodoro texnikasi va 4 ta AI Murabbiy persona birlashtirilgan.

## 🚀 Boshlash

### Talablar

- **Node.js** v18+
- **npm** yoki **pnpm**

### O'rnatish

```bash
# Reponi clone qiling
git clone https://github.com/SHoWMaN2441/life-reset.git
cd life-reset

# Bog'liqliklarni o'rnating
npm install

# Development serverini ishga tushiring
npm run dev
```

Brauzerda **[http://localhost:3000](http://localhost:3000)** ni oching.

### Build (Production)

```bash
npm run build
npm start
```
